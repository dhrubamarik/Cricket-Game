🏏 Bat Ball Stumps Game

A fun and interactive Cricket-themed web game built using HTML, CSS, and JavaScript.
This game is inspired by the classic Rock-Paper-Scissors logic, but redesigned with cricket elements.

🎮 Game Logic 

🏏 Bat beats Ball

🏐 Ball beats Stumps

🪵 Stumps beat Bat

The player competes against the CPU, and the winner is decided based on the above rules.

🚀 Features

🎯 Simple and intuitive gameplay

🤖 Random CPU choice logic

📊 Score tracking (Wins, Losses, Draws)

🔄 Reset score functionality

💡 Interactive UI with visual feedback

📱 Responsive design

🛠️ Tech Stack :
HTML5 – Structure & Game logic

CSS3 – Styling & layout
